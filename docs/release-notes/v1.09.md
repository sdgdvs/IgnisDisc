## IgnisDisc v1.09

Free, open-source (MIT) CD/DVD burner, audio CD ripper and multi-disc archiver for Windows 10 and 11 (x64).

- **Installer** (`IgnisDisc-Setup.exe`, 149.2 MB, per-user, no admin rights): `1D175C5FCAE9A1D4929113B62D5B3C9F52A1705B335692ED7199BF0BCEB4A3F2`

Builds are not code-signed yet, so Windows SmartScreen may warn on first run.

### New
- **FLAC support built in**: FLAC files are decoded directly (no codec needed), including 24-bit, high sample rates
  (88.2/96/192 kHz) and surround files, which are folded down to stereo. Tags (title, artist, album, ISRC…) are read.
- **CUE sheets with FLAC/WAV**: burn albums described by a `.cue` file, whether the album is one file per track or a
  single file for the whole album.
- **Playlists**: add tracks from `.m3u`, `.m3u8` and `.pls` playlists.
- **Audio extras**: loudness leveling, crossfade between tracks (gapless Disc-at-Once only), a 30-second track
  preview, and a printable jewel-case insert with the track list.
- **Disc copy**: copy a disc in one step, with one drive (it asks you to swap discs) or two, and make several copies
  in a row. Audio CDs are copied track by track.
- **Older image formats**: burn, verify and convert Nero (`.nrg`), Alcohol 120% (`.mdf`/`.mds`) and CloneCD
  (`.ccd`/`.img`) images, including Mode 2 / XA discs (PlayStation, Video CD). `ignisdisc-cli burn-iso` and `verify`
  accept these formats too.

### Changed
- The installer now lists the publisher as "tetherworks" in Apps & Features.

### Hardened before release
The new features above went through an adversarial audit before this release; these problems were found and fixed:
- Large high-resolution FLAC files could use several GB of memory or fail; they now use about as much memory as the
  CD audio they produce.
- Converting 88.2/96/192 kHz audio to CD rate no longer folds inaudible high frequencies back into the audible range.
- A damaged FLAC frame is replaced by a short silence instead of noise, and later tracks keep their timing.
- EAC-style CUE sheets with gaps appended to the previous track now import every track correctly.
- Verify-after-burn no longer reports a false failure for audio CUE sheets; it says why audio can't be compared
  bit-for-bit.
- Crossfaded transitions now play once (previously the overlap was heard twice).
- Older `.m3u` playlists saved in Windows' ANSI encoding now find files with accented names.
- Legacy images larger than 2 GB (DVDs) no longer fail to burn or verify.

### Known limitations
- CD-Text, test writes and DVD+R book type are not available on physical drives yet (Windows' burning service
  cannot do them). See the [roadmap](https://github.com/tether-works/IgnisDisc/blob/master/docs/ROADMAP.md).
- Blu-ray media are not supported yet.
- DVD-Video authoring needs `ffmpeg.exe`.
- Disc copy and the new audio features have been tested against the built-in virtual drive; please report results
  from real drives.
