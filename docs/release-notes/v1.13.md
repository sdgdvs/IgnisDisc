## IgnisDisc v1.13

Free, open-source (GPL-3.0-or-later) CD/DVD burner, audio CD ripper and multi-disc archiver for Windows 10 and 11 (x64).

Builds are not code-signed yet, so Windows SmartScreen may warn on first run.

### Direct drive commands now write DVDs (experimental, off by default)
The direct writer introduced for CDs in v1.12 now also writes data DVDs ("Direct drive commands (experimental)" on the Data Disc and Disc Image screens, `--native` on `burn-iso` and `burn-data`). Every direct burn is read back sector by sector afterwards, and the Windows writer stays the default.
- **DVD-R and DVD-RW**: written in one pass and closed by the drive, or left open for more sessions (`--no-close`). Laser-off test writes work on these discs (`--test-write`).
- **DVD+R**: written and finalized; if a drive refuses to finalize, the session is closed instead and the result says the disc can still be added to.
- **DVD+RW, DVD-RW in overwrite mode and DVD-RAM**: written from the start of the disc. A new DVD+RW is formatted first; a partly formatted DVD-RW is expanded first. A disc that already holds files is only written over when you allow it (`--overwrite`, or "replace" in the app). An unformatted DVD-RAM is refused with a message.
- **Speed** is taken from the drive's own list for the inserted disc and set before writing, never left to Windows; the result reports the speed measured while writing.
- **Tried on real discs** on one drive (LG GP60NB50): DVD-R test writes; a DVD-R closed in one pass; a DVD-R left open, to which the Windows writer then added a second session; a used DVD+RW written over; a new DVD+RW formatted and written. Every file read back identical. **DVD+R, DVD-RW and DVD-RAM have so far run only against the built-in drive simulator.**
- Dual-layer DVDs and Blu-ray discs are still burned by the Windows writer, and the result says so.

### Easier to use
- **The Audio CD screen shows the track list at the default window size.** Before, the list was squeezed to about one row and the "drop files here" hint was hidden. Every screen's title and description now share one line.
- **Small finished DVDs are no longer called "CD-ROM"**: the disc type comes from what the drive reports (a closed DVD-R shows as DVD-ROM, as the drive itself reports it).

### Fixed
- **Installer shortcuts**: every install now removes IgnisDisc shortcuts left by earlier versions (including the first builds' "CdBurner Optical Studio" names and duplicates in the Start menu) and writes fresh Desktop and Start menu shortcuts. Setup reports a shortcut it could not write instead of finishing silently, and shows the installed version read from the program itself (1.08 left "1.07" in Apps & Features).
- **Replacing the contents of a DVD+RW or DVD-RAM**: the check after the burn could read from where the old data ended instead of from the start of the disc, where the new data is written.

### Known limitations
- Direct drive commands are experimental and have been tried on one drive model only; DVD+R, DVD-RW and DVD-RAM have not been tried on real discs yet.
- On a drive that keeps showing a simulated session after a test write, a real burn needs the disc reloaded first.
- After a session is added to a DVD, Windows may go on showing only the earlier files until the disc is taken out and put back in.
- Dual-layer DVDs and Blu-ray discs always use the Windows writer; Blu-ray burning has never been tried on a real drive.
- No disc from this release has been played in a stand-alone CD or DVD player.
- Discs left open for more sessions hold file names of up to 64 characters.
- Burns through the Windows writer report the speed that was asked for, not the speed measured.
- Disc copy has been tested against the built-in virtual drive; please report results from real drives.
