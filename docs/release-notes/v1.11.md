## IgnisDisc v1.11

Free, open-source (GPL-3.0) CD/DVD burner, audio CD ripper and multi-disc archiver for Windows 10 and 11 (x64).

### Downloads and SHA-256 checksums
- **Installer** (`IgnisDisc-Setup.exe`, 81.8 MB, per-user, no admin rights): `EFC95F5798642B1739ABCCD9D50D7A2FAEBB0F00F6AF6EDBD3389DBEDF1277AF`
- **Portable** (`IgnisDisc-Portable-win-x64.zip`, 81.1 MB): `AB8A38252A27527B632DBA3D6173051F5645270331552AD1DFB10D80882EBE6A`

Builds are not code-signed yet, so Windows SmartScreen may warn on first run.

### Native SCSI writer (experimental laser-off test write) & drive diagnostics
- **Session-at-Once audio test write** (`ignisdisc-cli burn-audio --native --test-write`): sends write parameters (mode page `0x05`) with the Test Write bit verified before writing, `SEND CUE SHEET`, R-W sub-channel CD-Text in the lead-in, and audio sectors with the laser off, then checks that the disc remains unwritten. Tested on a physical HL-DT-ST GP60NB50 with a blank CD-R. Real native burns remain disabled for now; IMAPIv2 is still the default for all real burns.
- **Read-only drive capability probe & Media ID / ATIP / ADIP inspection**: Drive Utilities, `drives --json`, `media-info --json` and the new `drive-report` command read MMC write feature descriptors (`GET CONFIGURATION` `0x46`), Write Parameters mode page `0x05` (including the CD Mastering R-W CD-Text bit), and physical disc manufacturer/dye IDs (CD-R/RW ATIP via `READ TOC/PMA/ATIP` format `0x04`, DVD±R/RW and BD MID via `READ DISC STRUCTURE` `0xAD`).
- **Drive compatibility report** (`ignisdisc-cli drive-report --drive <id>` and Drive Utilities): builds a copy-paste Markdown report for the GitHub drive-compatibility issue form, omitting the Windows device path.
- **Surface scan CSV export**: `ignisdisc-cli scan --drive <id> --csv <file.csv>` and *Export Scan CSV* in Drive Utilities export per-block transfer rate and sector scan results.

### Burn queue, image conversions, and archival
- **Burn queue**: queue multiple data images (`.iso`, `.nrg`, `.mdf`/`.mds`, `.ccd`/`.img`) in Image Studio to burn one after another, with safety checks that refuse audio `.bin`/`.cue` sheets and protect existing data on rewritable discs.
- **After-burn actions**: eject disc, play a completion sound, or schedule a 60-second cancellable Windows shutdown (`shutdown /s /t 60`) after verification finishes.
- **Image format conversions**: convert between `.bin`/`.cue` and `.iso` (`BIN/CUE ↔ ISO`) and convert `.nrg`, `.mdf`/`.mds` and `.ccd`/`.img` to `.bin`/`.cue` as well as `.iso` in Image Studio.
- **Self-contained archive verification scripts**: `archive-stage` now writes `VERIFY.BAT`, `VERIFY.PS1` and `README-RECOVERY.TXT` onto every spanned archive disc so discs can be verified using built-in OS tools without IgnisDisc installed.
- **Disc copy fix**: fixed a bug where Raw Clone Mode burned staged 2,352-byte sectors as 2,048-byte data, and ensured audio CDs always copy track by track. Mixed-mode / Enhanced CDs are detected from the TOC with a clear notice that only the audio tracks are copied.

### Audio ripping & 1-click optional tools
- **ReplayGain 2.0 and embedded cover art**: `ignisdisc-cli rip-audio --format flac` calculates ITU-R BS.1770-4 track and album ReplayGain tags (verified against EBU Tech 3341 signals) and embeds front cover art when passed `--cover <image>`.
- **1-click FFmpeg & par2 installers**: Settings, DVD-Video Studio, and Archive Studio now include 1-click buttons to download and extract an official LGPL `ffmpeg.exe` build (into `%LOCALAPPDATA%\Programs\ffmpeg\`) and `par2.exe` (`par2cmdline`, into `%LOCALAPPDATA%\Programs\par2cmdline\`) together with their license files.
- **1-click MusicBrainz lookup**: Audio CD Studio adds a **Lookup MusicBrainz** button to fetch and fill in album and track titles from the inserted CD's Table of Contents before or without ripping, plus default toggles for MusicBrainz and AccurateRip in Settings.

### Platform & accessibility
- **Opt-in update check**: optional startup/manual update check against GitHub Releases (off by default in Settings).
- **Screen-reader labels**: `AutomationProperties.Name` added across studio views and dialogs.
- **Windows ARM64 build**: verified in CI (`Build-Installer.ps1 -Runtime win-arm64`).

### Known limitations
- Real burns still go through Windows' IMAPIv2 service, so physical lead-in CD-Text and DVD+R book type are not written on real burns yet (`--native --test-write` runs with the laser off only). See the [roadmap](https://github.com/tether-works/IgnisDisc/blob/master/README.md#roadmap).
- Blu-ray media are not supported yet.
- Disc copy has been tested against the built-in virtual drive; please report results from real drives.
