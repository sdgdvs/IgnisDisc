## IgnisDisc v1.10

Free, open-source (MIT) CD/DVD burner, audio CD ripper and multi-disc archiver for Windows 10 and 11 (x64).

### Downloads and SHA-256 checksums
- **Installer** (`IgnisDisc-Setup.exe`, 71.2 MB, per-user, no admin rights): `9640B9A154CF5852ECB18696AFBB0EFD17D027E97A74FB970EBDBA42615AF618`
- **Portable** (`IgnisDisc-Portable-win-x64.zip`, 70.6 MB): `AA9C4274059BC6737A69D7F3B60683E9242315E1329AF9D46382C008D7A25E87`

Builds are not code-signed yet, so Windows SmartScreen may warn on first run.

### Smaller installer
- The installer download is about half the size (149.2 MB in v1.09). The install wizard is unchanged; it now shares
  the app's copy of .NET instead of carrying a second one.
- The installed uninstaller is a few hundred KB instead of a 149 MB copy of the installer. Upgrading from an earlier
  version replaces the old copy and removes files the new version no longer uses.
- Uninstalling now removes the install folder completely, and only removes the shortcuts and Apps & Features entry
  that belong to the copy being uninstalled.

### Audio
- High-resolution WAV files (88.2/96/192 kHz) now get the same band-limited conversion to CD rate as FLAC, so
  inaudible high frequencies are no longer folded back into the audible range. Surround WAV files keep their centre
  channel when folded down to stereo.
- 24-bit audio is reduced to 16-bit with dither, which keeps quiet detail (fade-outs, reverb tails) instead of
  truncating it. Audio that is already 16-bit, and digital silence, are copied bit-for-bit.
- Previewing a track no longer freezes the window while a long album decodes, and the play indicator resets when the
  30-second preview ends.

### Project
- Every change is now built and tested automatically on GitHub (Windows, all tests, warnings treated as errors).
- Security reports can be filed privately (see `SECURITY.md`); drive compatibility reports have their own form.

### Known limitations
- CD-Text, test writes and DVD+R book type are not available on physical drives yet (Windows' burning service
  cannot do them). See the [roadmap](https://github.com/tether-works/IgnisDisc/blob/master/docs/ROADMAP.md).
- Blu-ray burning has not been tested on real Blu-ray media.
- DVD-Video authoring needs `ffmpeg.exe`.
- Disc copy has been tested against the built-in virtual drive; please report results from real drives.
