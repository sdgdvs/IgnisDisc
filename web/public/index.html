A free, open-source CD and DVD burner and audio CD ripper for Windows.

IgnisDisc burns data discs, ISO images and audio CDs, rips audio CDs with AccurateRip verification, and archives large folders across several discs. It is one desktop app (IgnisDisc.exe) plus a command-line tool (ignisdisc-cli.exe) for scripts. It burns through Windows' built-in burning service (IMAPIv2), so it needs no extra drivers.

02 // Features

No paid SDKs or bundled software
AUDIO CD RIPPING

Secure ripping with AccurateRip

Reads audio directly from the drive with C2 error pointers and repeated reads of suspect sectors, corrects for your drive's read offset (detected from any disc in the AccurateRip database), checks the result against AccurateRip, and saves WAV or FLAC with a .cue sheet. Track names can be looked up on MusicBrainz.

AUDIO CD BURNING

Gapless or Track-at-Once audio CDs

Burns audio CDs from WAV, FLAC, MP3 and M4A, either gapless (Disc-at-Once) or with gaps between tracks (Track-at-Once). Optional peak normalization. CD-Text is saved in projects and .cue files but is not yet written to discs in real drives.

DATA DISCS & IMAGES

ISO 9660, Joliet and UDF

Builds images with ISO 9660, Joliet and a UDF 1.02 bridge, so long file names work on Windows, macOS and Linux. Appends sessions to multi-session discs, makes bootable BIOS + UEFI discs, and rips discs to .iso or .bin + .cue.

COLD STORAGE

Multi-disc archives

Splits a folder that is too big for one disc across numbered discs, writes a manifest with a SHA-256 hash of every file onto each disc, and can add PAR2 recovery data (with par2.exe) so damaged files can be repaired later.

DRIVE UTILITIES

Erase, scan and inspect

Quick and full erase of CD-RW and DVD-RW, a surface scan that maps readable, slow and unreadable areas, and a media inspector that shows disc type, capacity, sessions and supported speeds.

SAFETY

Checks before it writes

Refuses to burn over a finalized CD-RW until it has been erased, asks before replacing the files on a used DVD+RW or DVD-RAM, and can verify every burn by reading it back.

03 // Command line (ignisdisc-cli.exe)

Every command accepts --json
PowerShell examples EXIT CODE 0 = SUCCESS 
# 1. List drives and inspect the disc
PS C:\> ignisdisc-cli.exe drives
PS C:\> ignisdisc-cli.exe media-info --drive H:

# 2. Multi-session data burn (first session left open, second appended)
PS C:\> ignisdisc-cli.exe burn-data --drive H: --input "C:\Batch1" --label "ARCHIVE_S1" --no-close --verify
PS C:\> ignisdisc-cli.exe burn-data --drive H: --input "C:\Batch2" --label "ARCHIVE_S2" --verify

# 3. Build and burn a BIOS + UEFI bootable ISO
PS C:\> ignisdisc-cli.exe build-iso --input "C:\WinPE" --output "C:\WinPE.iso" `
    --boot-bios "C:\WinPE\etfsboot.com" --boot-uefi "C:\WinPE\efisys.bin"
PS C:\> ignisdisc-cli.exe burn-iso --drive H: --iso "C:\WinPE.iso" --verify

# 4. Burn a gapless audio CD, then rip it back to FLAC
PS C:\> ignisdisc-cli.exe burn-audio --drive H: --tracks "01.wav,02.wav,03.flac" --title "Mix" --dao
PS C:\> ignisdisc-cli.exe rip-audio --drive H: --output "C:\Rips" --format flac --secure --verify-accuraterip

# 5. Plan a multi-disc archive with 10% PAR2 recovery data, then check a burned disc
PS C:\> ignisdisc-cli.exe archive-stage --input "C:\Photos" --staging "C:\Stage" --media cd --redundancy 10
PS C:\> ignisdisc-cli.exe archive-verify --path H:\ --json
