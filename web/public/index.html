A clean, modern Windows CD/DVD burner, AccurateRip audio ripper, and multi-disc PAR2 archiver.

Most Windows optical disc utilities (ImgBurn, CDBurnerXP, Exact Audio Copy) haven't been updated in a decade, bundle adware in mirror installers, or require juggling three separate tools. IgnisDisc packs 1-click data/ISO burning, gapless Audio CD mastering, hardware C2/AccurateRip extraction, and multi-disc PAR2 cold storage into one self-contained Windows 10/11 desktop app (IgnisDisc.exe) and headless CLI (ignisdisc-cli.exe).

01 // What's Inside the Binary

No external burning SDKs or paid DLLs
COLD STORAGE / r/DataHoarder

Multi-Disc Archive Studio + PAR2

Point IgnisDisc at a folder larger than a single disc and it bin-packs files across numbered discs (Disc 1..N), generates par2cmdline-turbo parity recovery blocks, writes a self-contained ARCHIVE_MANIFEST.json (with per-file SHA-256 hashes) onto every disc, and verifies or repairs damaged reads straight from the drive.

AUDIO EXTRACTION & MASTERING

Hardware C2 Secure Rip & AccurateRip

Extracts audio CDs via raw SCSI READ CD (0xBE) with hardware C2 error pointers and multi-pass MajorityVote retry, automatic drive read-offset calibration, MusicBrainz metadata lookup, AccurateRip v1/v2 checksum verification, and native Media Foundation FLAC/WAV encoding. Also burns gapless DAO/TAO Audio CDs with binary CD-Text (0x80..0x8F + CRC-16).

FILE SYSTEMS & MULTI-SESSION

ISO 9660 + Joliet + UDF 1.02 Bridge

Pure managed filesystem compiler generating simultaneous ISO 9660 Level 2, Joliet (UCS-2 Big Endian), and OSTA UDF 1.02 Bridge structures (AVDP at LBA 256 & N-1). Supports Multi-Session CD/DVD appending by reading prior session TOCs via SCSI 0x51/0x43 and merging previous directory trees.

BOOTABLE MEDIA & DVD-VIDEO

Dual BIOS + UEFI El Torito & VIDEO_TS

Authors hybrid bootable Windows PE / Linux ISOs with both x86 BIOS (0x00) and UEFI ESP (0xEF) validation/section entries, plus standalone DVD-Video discs with strict 32 KB (16-sector ECC block) padding between .IFO and .BUP headers.

OPTICAL DIAGNOSTICS

Full-TOC Surface Scan & Rewritable Guards

Scans data and multi-track audio discs via SCSI Format 0x02 Full TOC lead-out discovery, maps good/slow/bad LBA blocks, performs quick/full CD-RW & DVD-RW erases, sets DVD+R/RW book-type bitsetting, and issues explicit SCSI 0x1B (START STOP UNIT) spindle spin-down.

SAFETY & ERGONOMICS

Max-Speed Negotiation & Coaster Prevention

Automatically negotiates the highest write speed supported by the inserted media, refuses to overwrite finalized CD-RWs without a clean erase first, and warns before overwriting existing data on formatted DVD+RW media.

02 // Headless CLI (ignisdisc-cli.exe)

Structured JSON output & deterministic exit codes
PowerShell — Automated Burning, Secure Ripping & Archival EXIT 0 = VERIFIED 
# 1. Inspect drives & media status
PS C:\> ignisdisc-cli.exe drives
PS C:\> ignisdisc-cli.exe media-info --drive H:

# 2. Multi-session data burn (Session 1 open, Session 2 appended & verified)
PS C:\> ignisdisc-cli.exe burn-data --drive H: --input "C:\Batch1" --label "ARCHIVE_S1" --no-close --verify
PS C:\> ignisdisc-cli.exe burn-data --drive H: --input "C:\Batch2" --label "ARCHIVE_S2" --verify

# 3. Build & burn a dual BIOS + UEFI bootable ISO image
PS C:\> ignisdisc-cli.exe build-iso --input "C:\WinPE" --output "C:\WinPE.iso" `
    --boot-bios "C:\WinPE\etfsboot.com" --boot-uefi "C:\WinPE\efisys.bin"
PS C:\> ignisdisc-cli.exe burn-iso --drive H: --iso "C:\WinPE.iso" --verify

# 4. Burn a gapless DAO Audio CD from WAV/FLAC, then C2 secure-rip back to FLAC
PS C:\> ignisdisc-cli.exe burn-audio --drive H: --tracks "01.wav,02.wav,03.flac" --title "Mix" --dao
PS C:\> ignisdisc-cli.exe rip-audio --drive H: --output "C:\Rips" --format flac --secure --verify-accuraterip

# 5. Stage a multi-disc archive with 10% PAR2 recovery & verify the burned disc
PS C:\> ignisdisc-cli.exe archive-stage --input "C:\Photos" --staging "C:\Stage" --media cdr --redundancy 10
PS C:\> ignisdisc-cli.exe archive-verify --path H:\ --json
