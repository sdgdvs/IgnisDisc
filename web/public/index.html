Burn CDs and DVDs, rip music CDs, and back up folders on Windows.

IgnisDisc is a free, open-source disc burner and audio CD ripper for Windows 10 and 11. Burn files, folders, and .iso images to CD or DVD, make audio CDs from WAV, FLAC, MP3, or M4A tracks, rip your music CDs to lossless audio with automatic track names, or split a large folder across several numbered backup discs. It uses Windows' built-in disc burning service — no extra drivers, no ads, no bundled offers, and no tracking.

Technical Overview & Subsystem Architecture

Under the hood, IgnisDisc Optical Studio ships as a native .NET 10 WPF desktop application (IgnisDisc.exe) and scriptable command-line tool (ignisdisc-cli.exe). It authors ISO 9660 + Joliet + UDF 1.02 bridge data volumes, El Torito BIOS/UEFI boot images, legacy disc images (.nrg, .mdf/.mds, .ccd/.img), and Red Book DAO/TAO audio CDs via Windows IMAPIv2. Sector extraction uses Win32 SCSI pass-through with 294-byte C2 error pointers, AccurateRip checksum verification, and drive read-offset detection, alongside multi-disc cold archival with per-disc SHA-256 manifests, PAR2 recovery volumes, and a deterministic in-memory virtual optical drive simulator.

CdBurner.Core

  • Pure .NET IsoUdfImageBuilder authoring ISO 9660, Joliet UCS-2BE, OSTA UDF 1.02 Bridge, and El Torito BIOS/UEFI boot catalogs.
  • Streaming LegacyDiscImageConverter for .nrg, .mdf/.mds, and .ccd/.img (incl. Mode 2 / XA 2336B/2448B sectors).
  • RedBookPcmConverter (polyphase resampler + TPDF dither), built-in FlacFileCodec, CUE/playlist parsers, and ArchiveSpanPlanner.

CdBurner.Hardware

  • Background ApartmentState.MTA worker (MtaBurnWorker) driving IDiscFormat2Data, IDiscFormat2TrackAtOnce, IDiscFormat2RawCD, and IDiscFormat2Erase.
  • PhysicalSectorReader + Win32ScsiTransport (IOCTL_SCSI_PASS_THROUGH_DIRECT, Full TOC 0x02, READ CD with C2 pointers).
  • Deterministic VirtualDiscBackend simulating 25 optical drive and media firmware personas in CI.

CdBurner.Cli & App

  • IgnisDisc.exe: WPF desktop studio with 8 dedicated workspaces and OS-synced Dark/Light theme (ThemeManager).
  • ignisdisc-cli.exe: 16 automation commands with --json output and non-interactive overwrite/erase safety guards.
  • Two-stage 81.8 MB installer (net48 bootstrapper + shared-runtime Uninstall-IgnisDisc.exe).

Native SCSI MMC Writer

  • Capability Probe: Read-only GET CONFIGURATION (0x46) and Mode Page 0x05 write capability inspector.
  • Test Write (Experimental): burn-audio --native --test-write sends Session-at-Once cue sheets and R-W lead-in CD-Text with the laser off (verified on physical CD-R).
  • Safety Rail: IMAPIv2 remains the default for all real burns; real native burns are not enabled yet.
