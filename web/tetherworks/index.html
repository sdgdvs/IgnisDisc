IgnisDisc Optical Studio (v1.12)

Free, open-source CD and DVD burner, audio CD ripper, and multi-disc backup tool for Windows 10 and 11. Burn files, folders, and disc images, make music CDs, rip audio CDs to lossless WAV or FLAC with automatic track names, or split large folders across several discs — from the desktop app or the command line.

SUBSYSTEM TECHNICAL SPECIFICATION
Data & Boot Mastering ISO 9660 + Joliet UCS-2BE + UDF bridge (UDF 1.02 to 2.60), hybrid BIOS/UEFI El Torito boot catalogs, multi-session append, optional SHA256SUMS / BLAKE3SUMS hash lists, and streaming .nrg / .mdf / .ccd conversion.
Audio CD Rip & Burn Secure SCSI extraction with 294-byte C2 error pointers, AccurateRip verification, drive offset detection, MusicBrainz lookup, and Red Book DAO/TAO burning (WAV, FLAC, MP3/M4A, CUE). Optional direct drive commands (experimental) write CD-Text and read the disc back.
Multi-Disc Cold Archive Folder spanning across discs with per-disc SHA-256 manifests, optional PAR2 recovery data that fills each disc, and a recover command for damaged discs.
Hardware Verification Tested on physical CD-R, CD-RW, DVD-R, and DVD+RW media on one drive model, plus over 1,200 automated tests.
