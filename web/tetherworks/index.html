IgnisDisc Optical Studio (v1.08)

ignisdisc.tetherworks.dev ↗ Source & Release

A modern, single-binary Windows 10/11 replacement for aging optical disc tools. IgnisDisc brings data/ISO burning, gapless Audio CD mastering, hardware C2/AccurateRip audio extraction, and multi-disc PAR2 cold-storage archiving into one clean desktop studio and scriptable CLI.

Key capabilities
  • 1-click Data, ISO/UDF, Audio CD, and DVD-Video burning
  • Secure audio CD ripping to FLAC/WAV with AccurateRip & MusicBrainz lookup
  • Multi-disc cold storage archiver with SHA-256 manifests + PAR2 recovery
Verification & stack
  • Native .NET 10 over Windows imapi2.dll COM and direct SCSI MMC-5 pass-through
  • 481 automated CI tests running against an in-memory virtual optical drive in ~6s
  • Validated end-to-end across physical CD-R, CD-RW, DVD-R, and DVD+RW media

KiloOS: A Return to 1999 (v0.4.0)

kilo.tetherworks.dev ↗

An exploration of 1999-era software minimalism. KiloOS is a self-contained retro desktop environment running directly in the browser—housing a fleet of 95 lightweight applications, system utilities, and arcade/strategy games designed to load instantaneously and run at a locked 60fps.

Inside the OS fleet (95 apps)
  • Games: KChrono (tri-epoch time-travel puzzler), KStarForge, KRogue, KCosmic, KFortress, KCyber, KMech
  • System & Productivity: KTerm, KSys, KTask, KScript, KAudio, KFont, KDB
  • Virtual 1999 Web: KNet browser & KBBS bulletin board system
Quality & runtime guarantees
  • Zero bloated dependencies; instant cold start across the entire 95-app fleet
  • 4-layer security linter, immutability gate, and provenance attestation
  • Automated 60fps benchmark suite and HiDPI responsive verification

02 // Design Principles

How projects are built & tested
PRINCIPLE 01

Simulator-First Verification

Reliable software shouldn't depend on manual guesswork. Every project here is paired with a deterministic simulation harness—from an in-memory optical drive simulator (VirtualDiscBackend) that tests sector-level corruption in milliseconds, to automated 60fps visual and frame-budget verification suites.

PRINCIPLE 02

1999 Efficiency, Modern Reliability

Software should open immediately, do its job cleanly, and respect the machine it runs on. Projects published under tetherWorks ship as self-contained binaries or instant-loading web environments with zero telemetry, zero ads, and no account requirements.
