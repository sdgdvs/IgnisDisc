IgnisDisc Optical Studio (v1.08)

ignisdisc.tetherworks.dev ↗ Source & Release

A free, open-source CD and DVD burner and audio CD ripper for Windows 10 and 11. It burns data discs, ISO images and audio CDs, rips audio CDs with AccurateRip verification, and archives large folders across several discs, from a desktop app or a command-line tool.

Key capabilities
  • Data disc, ISO and audio CD burning, with verify after burn
  • Secure audio CD ripping to FLAC/WAV with AccurateRip and MusicBrainz lookup
  • Multi-disc archives with SHA-256 manifests and optional PAR2 recovery data
How it's built and tested
  • .NET 10; burns through Windows' built-in burning service (IMAPIv2) and reads discs directly from the drive
  • Automated tests run against a built-in virtual drive
  • Tested on real CD-R, CD-RW, DVD-R and DVD+RW media
Download the installer or portable ZIP from the project page or GitHub Releases.

KiloOS: A Return to 1999 (v0.4.38)

kilo.tetherworks.dev ↗

An exploration of 1999-era software minimalism. KiloOS is a retro desktop environment that runs in the browser, with 104 small applications, system utilities and games.

Inside (104 apps)
  • Games: KChrono (tri-epoch time-travel puzzler), KStarForge, KRogue, KCosmic, KFortress, KCyber, KMech
  • System & Productivity: KTerm, KSys, KTask, KScript, KAudio, KFont, KDB
  • Virtual 1999 Web: KNet browser & KBBS bulletin board system
